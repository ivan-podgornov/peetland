# Peetland

Peetland — мир, в котором NPC живут своей жизнью. У каждого есть цель, характер и вещи, и как
добиться цели, он решает сам: никто не пишет ему сценарий. Сейчас Peetland — это мод для GTA San
Andreas.

- [Бомж-алкаш](./core/homeless/README.md) — пока единственный житель мира: хочет напиться и добывает
  на пойло как может.
- [NPC](./core/npc/README.md) — кто такие NPC и что у них есть.
- [Документация](./docs/index.md) — описание мира для игрока, устройство проекта и правила
  разработки. Она же собирается в сайт на GitHub Pages репозитория.
- [CONTRIBUTING.md](./CONTRIBUTING.md) — как устроена разработка.
