Документация

Документация лежит в пакете docs и собирается в сайт на Docusaurus. Страницы — обычный Markdown без MDX прямо в пакете, рядом с его конфигом, диаграммы рисуются на Mermaid. Локально сайт запускается командой npm start -w @peetland/docs.

Документация пакетов​

Документация пакета лежит в самом пакете, в двух файлах:

  • README.md — продуктовая. Что пакет даёт игроку: какие у NPC цели, как он себя ведёт и от чего это зависит. Пишется для игрока, человеческим языком и без деталей реализации: без имён из кода, цифр баланса, шагов алгоритма, которым NPC добивается цели, и подробностей конкретной игры. Очевидное для игрока, например что NPC поворачивается к месту, не описывается. Если пакету нечего рассказать игроку, как пакетам toolkit, README короткий: что это за пакет и ссылка на CONTRIBUTING.
  • CONTRIBUTING.md — техническая. Как пакет устроен и как с ним работать: классы, интерфейсы, зависимости, помощники для тестов. Длинные темы выносятся в папку docs пакета.

Документация пакетов на сайте​

Сайт читает документацию прямо из пакетов, без копий. Пакеты каждого слоя читает свой инстанс плагина документации, и страницы пакета лежат по адресу /<слой>/<пакет>/:

  • README — продуктовая страница, например /core/homeless/. Продуктовые страницы стоят в сайдбаре «Продукт» в верхнем меню. Сайдбар собирается руками в docs/sidebars-core.ts, поэтому новый продуктовый README нужно поставить туда.
  • CONTRIBUTING и папка docs — техническая документация, например /core/homeless/CONTRIBUTING/. Она собирается в сайдбар раздела «Пакеты» сама.

README и CONTRIBUTING пакетов ссылаются друг на друга обычными относительными ссылками, например ../psyche/README.md, и на сайте они работают так же, как на GitHub. Ссылки должны вести на Markdown внутри пакетов своего слоя, иначе сборка сайта упадёт на битой ссылке.
