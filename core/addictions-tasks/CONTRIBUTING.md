# @peetland/addictions-tasks

Задачи удовлетворения зависимостей NPC (`Addiction` из `@peetland/addictions`). Задача
«удовлетворить зависимости» — слой зависимостей корневой задачи NPC (см.
[корневую задачу](../world/CONTRIBUTING.md#корневая-задача)). Как это выглядит для игрока, описано в
[README.md](./README.md).

## Задачи

- **Удовлетворить зависимости** (`AddictionsTask`) — метод на каждую зависимость. Метод подходит,
  если его зависимость тянет (`AddictionStatus.Craving`), и планирует её удовлетворение. Пока такой
  метод один — `satisfy-alcoholism`. Если удовлетворить нечем или ничего не тянет, задачу не
  спланировать, и NPC занимается тем, что ниже в корневой задаче. Тяга не прерывает текущий план:
  удовлетворять её NPC идёт, когда план закончится.
- **Удовлетворить алкоголизм** (`SatisfyAlcoholismTask`) — выпить пойло в месте для распития
  (`PlaceType.DrinkingSpot`). Методы в порядке приоритета:
  - `drink-here` — если пойло есть и NPC в радиусе `SatisfyAlcoholismTask.SPOT_RADIUS` от места
    для распития, выпить там же;
  - `go-and-drink` — если пойло есть и места для распития есть, дойти до ближайшего и выпить;
  - `buy-and-drink` — если пойла нет, а денег хватает на `BOOZE_PRICE` и есть магазин и место для
    распития, купить пойло в ближайшем магазине (`BuyBoozeTask`), дойти до места для распития,
    ближайшего к магазину, и выпить.

  Пьёт NPC задачей «выпить» (`DrinkTask` из `@peetland/npc-tasks`): она и сообщает зависимостям,
  что он выпил. Какой предмет в инвентаре — пойло, задача спрашивает у классификатора предметов
  (`IItemClassifier`).

- **Купить пойло** (`BuyBoozeTask`) — дойти до переданного магазина, повернуться к прилавку и купить
  бутылку пойла за `BOOZE_PRICE`.

Задачи одинаковые для всех типов NPC. Если способ доступен не всем, это решают предусловия метода
по типу NPC из состояния (`state.self.kind`), а не пакет типа NPC.

## Фабрика

`AddictionsTaskFactory` реализует `IAddictionsTaskFactory` и создаёт задачи пакета. Снаружи она
получает геометрию, места, случайные числа и таймер, а фабрику задач NPC (`NpcTaskFactory`) и
классификатор предметов (`ItemClassifier`) по умолчанию собирает сама. На каждый вызов задача новая:
дерево задач не делится между NPC. Наружу пакет показывает фабрику и `AddictionsTask`, а задачи
отдельных зависимостей создаются только фабрикой.

## Для тестов

Точка входа `@peetland/addictions-tasks/dev` даёт:

- мок фабрики (`createMockedAddictionsTaskFactory`): задачи, которые не переданы, — заглушки,
  которые всегда можно выполнить. Его же по умолчанию получает задача из
  `createSatisfyAlcoholismTask`;
- зависимости фабрики (`createAddictionsTaskFactoryDeps`), в которых мест нет;
- задачу удовлетворить алкоголизм (`createSatisfyAlcoholismTask`). Места для неё — в
  `@peetland/places/dev`: если места не переданы, в мире есть магазин `TEST_SHOP` и место для
  распития `TEST_SPOT` (`createPlacesWithShopAndSpot`).
