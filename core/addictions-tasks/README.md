# Удовлетворение зависимостей

Как NPC удовлетворяет свои зависимости (см. [Зависимости](../addictions/README.md)): что делает,
когда его тянет выпить. Способы одни и те же для всех NPC.

Пока не тянет, NPC о пойле не думает и занят своими делами. Когда потянет, он идёт пить в
ближайшее место для трапезы, а если уже стоит в нём, пьёт сразу. Если пойла при себе нет, но
хватает денег, он покупает его в ближайшем магазине и идёт пить в место для трапезы, ближайшее к
магазину. Если нет ни пойла, ни денег, тяга подождёт: NPC пойдёт добывать на пойло по своим делам.

Базовые потребности приоритетнее зависимостей и удовлетворяются в первую очередь (см.
[Удовлетворение потребностей](../needs-tasks/README.md)).
