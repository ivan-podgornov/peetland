# @peetland/game

Интерфейсы игры, которые реализует мод: акторы, объекты и геометрия.

## Акторы

Актор реализует `IActor`. Всё, что он делает со временем, например, идёт к точке, выполняется
командой `IActorCommand`. Актор выполняет одну команду за раз, она доступна в `currentCommand`:
новая команда прерывает текущую, и её Observable завершается ошибкой. Команда сама вызывает `stop`,
когда выполнена, а `cancel` вызывает актор, когда её нужно прервать.

### Анимации

`playAnimation` проигрывает анимацию и возвращает Observable, который завершается, когда она
закончилась. Анимации задаются абстрактными id из `AnimationId`: они описывают, что делает персонаж
(«рыться в мусорке», «пить стоя»), а не то, какой анимацией игры это показано. Анимации могут быть
незаконченными, в цепочки их собирает HTN.

Таблица `ANIMATIONS` говорит, какие анимации зациклены. Зацикленная анимация повторяется, пока не
пройдёт время проигрывания, и это время обязательно передаётся вторым аргументом:
`actor.playAnimation('trash-search', 5000)`. Незацикленная идёт свою длительность, и передать для
неё время — ошибка.

### Деспавн

Фабрика акторов оборачивает актора в декоратор `DespawnableActor`. Он передаёт вызовы актору, а
после деспавна больше его не вызывает и выбрасывает ошибку из любого метода. Поэтому реализация
актора может не думать об использовании после деспавна: `despawn` вызовут один раз, и после него
ничего вызываться не будет. В `despawn` актору достаточно прервать текущую команду и удалить себя.

```ts
const actor = new DespawnableActor(new VirtualActor(options, deps));
```

## Виртуальный актор

`VirtualActorFactory` создаёт акторов, которые работают без игры и хранят всё в памяти. На них
тестируются задачи, NPC и мир.

```ts
import { VirtualActorFactory } from '@peetland/game';
import { Geometry } from '@peetland/geometry';
import { Timer } from '@peetland/timings';

const factory = new VirtualActorFactory(
  { animations: { pay: { duration: 4670 } /* ...и остальные анимации */ } },
  { geometry: new Geometry(), timer: new Timer() }
);
const actor = factory.create({ modelId: 230, position: { x: 0, y: 0, z: 0 } });
```

`goToCoords` при подписке сообщает текущую позицию, а затем раз в секунду по таймеру из зависимостей
сдвигает актора к точке по прямой со скоростью пешехода (5 км/ч ≈ 1,39 м/с) и сообщает новую
позицию. Когда актор входит в
радиус (без учёта высоты), Observable завершается.

`playAnimation` завершается, когда по таймеру проходит время проигрывания для зацикленной анимации
или длительность из таблицы для незацикленной. Анимации передаются
таблицей `animations` в опциях фабрики: для каждой анимации обязательна запись с длительностью.
Если записи или длительности нет, `playAnimation` выбрасывает ошибку.
