# @peetland/game

Интерфейсы игры, которые реализует мод: акторы, объекты и геометрия.

## Акторы

`Actor` содержит логику, общую для всех акторов, а то, как актор устроен на самом деле, описывает
состояние `IActorState`, которое передаётся в конструктор: как читать и менять позицию, какой
командой вести актора к точке и как его удалить.

### Команды

Всё, что актор делает со временем, например, идёт к точке, выполняется командой `IActorCommand`.
Актор выполняет одну команду за раз и хранит её в `currentCommand`: новая команда прерывает
текущую, и её Observable завершается ошибкой. Команда сама вызывает `stop`, когда выполнена, а
`cancel` вызывает актор, когда её нужно прервать.

### Деспавн

`despawn` прерывает текущую команду и переключает актора на состояние `DespawnedActorState`. После
этого любой метод актора выбрасывает ошибку, а `goToCoords` завершается ошибкой при подписке.

## Виртуальный актор

`VirtualActorFactory` создаёт акторов, которые работают без игры и хранят всё в памяти. На них
тестируются задачи, NPC и мир.

```ts
import { VirtualActorFactory } from '@peetland/game';
import { Geometry } from '@peetland/geometry';

const factory = new VirtualActorFactory({ geometry: new Geometry() });
const actor = factory.create({ modelId: 230, position: { x: 0, y: 0, z: 0 } });
```

`goToCoords` при подписке сообщает текущую позицию, а затем раз в секунду сдвигает актора к точке
по прямой со скоростью пешехода (5 км/ч ≈ 1,39 м/с) и сообщает новую позицию. Когда актор входит в
радиус (без учёта высоты), Observable завершается.
