# @peetland/game

Интерфейсы игры, которые реализует мод: акторы, объекты и геометрия.

## Виртуальный актор

`VirtualActorFactory` создаёт акторов, которые работают без игры и хранят всё в памяти. На них
тестируются задачи, NPC и мир.

```ts
import { VirtualActorFactory } from '@peetland/game';
import { Geometry } from '@peetland/geometry';

const factory = new VirtualActorFactory({ geometry: new Geometry() }, { speed: 2 });
const actor = factory.create({ modelId: 230, position: { x: 0, y: 0, z: 0 } });
```

Скорость задаётся в метрах в секунду. По умолчанию это скорость пешехода: 5 км/ч ≈ 1,39 м/с.

`goToCoords` при подписке сообщает текущую позицию, а затем раз в секунду сдвигает актора к точке
по прямой и сообщает новую позицию. Когда актор входит в радиус (без учёта высоты), Observable
завершается. Если вызвать `goToCoords` во время движения, предыдущее движение завершается ошибкой
и актор идёт к новой точке.

`despawn` завершает текущее движение ошибкой. После него любой метод актора выбрасывает ошибку.
