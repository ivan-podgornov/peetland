# @peetland/game

Интерфейсы игры, которые реализует мод: акторы, объекты и геометрия.

## Акторы

Актор реализует `IActor`. Всё, что он делает со временем, например, идёт к точке, выполняется
командой `IActorCommand`. Методы `goToCoords` и `playAnimation` только создают команду и возвращают
её. Выполняться она начинает, когда подписываются на Observable из `execute`:

```ts
actor
  .goToCoords(trashBin, 0.5)
  .execute()
  .subscribe({ complete: () => console.log('Пришёл') });
```

Актор выполняет одну команду за раз. Новая команда при подписке прерывает текущую, и Observable
текущей завершается ошибкой. Пока на новую команду не подписались, текущая выполняется дальше.
`cancel` прерывает команду. Если её прервали до подписки, при подписке Observable сразу завершится
ошибкой, а текущую команду она не прервёт.

Чтобы следить за текущей командой, актор оборачивает каждую команду, которую возвращает, в
`ActorCommandSlot`. Это временное решение: в #42 слот удаляется, команды прерываются при деспавне по
сигналу актора, а следить, чтобы актор выполнял одну команду за раз, будет вызывающий код.
Пока актор использует его так:

```ts
private readonly commands = new ActorCommandSlot();

goToCoords(coords: Vector3, completeRadius: number): IActorCommand<Vector3> {
  return this.commands.bind(new GoToCoordsCommand(/* ... */));
}

despawn(): void {
  this.commands.cancel(new Error('Актор деспавнен'));
}
```

Команды удобно писать, наследуясь от `Command` из `@peetland/actor-command`. Команды в старом формате
(с `start` и подписчиком в конструкторе) временно оборачиваются в `LegacyCommand`, пока их не
переведут на `Command`.

### Анимации

`playAnimation` возвращает команду проиграть анимацию. Её Observable завершается, когда анимация
закончилась. Анимации задаются абстрактными id из `AnimationId`: они описывают, что делает персонаж
(«рыться в мусорке», «пить стоя»), а не то, какой анимацией игры это показано. Анимации могут быть
незаконченными, в цепочки их собирает HTN.

Таблица `ANIMATIONS` говорит, какие анимации зациклены. Зацикленная анимация повторяется, пока не
пройдёт время проигрывания, переданное вторым аргументом:
`actor.playAnimation('trash-search', 5000)`. Если время не передать, она идёт свою длительность по
умолчанию. Незацикленная всегда идёт свою длительность, и передать для неё время — ошибка.

### Деспавн

Фабрика акторов оборачивает актора в декоратор `DespawnableActor`. Он передаёт вызовы актору, а
после деспавна больше его не вызывает и выбрасывает ошибку из любого метода. Поэтому реализация
актора может не думать об использовании после деспавна: `despawn` вызовут один раз, и после него
ничего вызываться не будет. В `despawn` актору достаточно прервать текущую команду и удалить себя.

```ts
const actor = new DespawnableActor(new GtaActor(options, deps));
```
