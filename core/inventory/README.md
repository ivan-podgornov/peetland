# Вещи

У каждого NPC есть вещи, которые он носит с собой:

- **деньги** — на них покупают;
- **пустые бутылки** — их находят в мусорках и сдают в приёмку за деньги;
- **пойло** — его покупают в магазине и выпивают, а пустая бутылка остаётся.
- **батон «Ромашка»** и **пицца «Смайл»** — еда: её съедают, когда голодны. Пицца сытнее батона.

Зачем NPC эти вещи, зависит от его типа, например см. [Бомж-алкаш](../homeless/README.md).
