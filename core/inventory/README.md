# Вещи

У каждого NPC есть вещи, которые он носит с собой. Пока вещей три:

- **деньги** — на них покупают;
- **пустые бутылки** — их находят в мусорках и сдают в приёмку за деньги;
- **пойло** — его покупают в магазине и выпивают, а пустая бутылка остаётся.

Сколько чего NPC может унести и что стоит сколько денег, зависит от типа NPC, например см.
[Бомж-алкаш](../homeless/README.md#деньги-и-бутылки).
