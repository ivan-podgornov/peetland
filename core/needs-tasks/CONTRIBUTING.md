# @peetland/needs-tasks

Задачи удовлетворения потребностей NPC: по одной составной задаче на потребность (`Need` из
`@peetland/needs`). Их планирует слой потребностей корневой задачи NPC (см.
[корневую задачу](../world/CONTRIBUTING.md#корневая-задача)).

## Задачи

- **Утолить голод** (`SatisfyHungerTask`) — восполнить сытость. Пока без методов: способов поесть
  нет.

Задачи одинаковые для всех типов NPC. Способы удовлетворить потребность — методы задачи. Если
способ доступен не всем, например рыться в мусорке за едой только бомжу, это решают предусловия
метода по типу NPC из состояния (`state.self.kind`), а не пакет типа NPC.

## Фабрика

`SatisfyNeedTaskFactory` реализует `ISatisfyNeedTaskFactory` и по потребности создаёт задачу,
которая её удовлетворяет. На каждый вызов задача новая: дерево задач не делится между NPC.

## Для тестов

Точка входа `@peetland/needs-tasks/dev` даёт мок фабрики (`createMockedSatisfyNeedTaskFactory`),
который на любую потребность возвращает переданную задачу.
