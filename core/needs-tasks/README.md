# Удовлетворение потребностей

Как NPC удовлетворяет свои потребности (см. [Потребности](../needs/README.md)): чем утоляет
голод. Способы одни и те же для всех NPC, но не каждый способ доступен каждому: например, рыться в
мусорке за едой станет только бомж.

Пока способов поесть нет: они появятся вместе с едой.
