# Потребности

У каждого NPC есть потребности: то, что со временем само заканчивается и что приходится восполнять.
Пока потребность одна — **сытость**. Она понемногу падает весь день, и к концу суток NPC, который
ничего не ел, совсем голоден. Поел — снова сыт.

Потребности бывают двух видов:

- **жизненные** — то, без чего NPC не может жить, например сытость;
- **зависимости** — то, без чего NPC жить не хочет, например выпить.

NPC сам следит за потребностями и, когда пора, занимается ими. Жизненные потребности для него
важнее зависимостей.
