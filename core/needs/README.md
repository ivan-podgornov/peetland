# Потребности

У каждого NPC есть потребности: то, что со временем само заканчивается и что приходится восполнять.
Пока потребностей две:

- **сытость** понемногу падает весь день, и к концу суток NPC, который ничего не ел, совсем голоден.
  Поел — снова сыт;
- **алкоголизм** — зависимость от пойла: чем сильнее NPC зависим, тем чаще его тянет выпить. Алкаша
  тянет раз в сутки, бомжа послабее — реже, а кого не тянет совсем, тот не пьёт. Выпил — тяга прошла.

Потребности бывают двух видов:

- **жизненные** — то, без чего NPC не может жить, например сытость;
- **зависимости** — то, без чего NPC жить не хочет, например выпить.

NPC сам следит за потребностями и, когда пора, занимается ими. Жизненные потребности для него
важнее зависимостей: от голода он бросает дела, а тяга ждёт, пока он закончит начатое.
