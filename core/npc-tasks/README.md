# @peetland/npc-tasks

Примитивные задачи, которые нужны любому NPC: идти к координатам, повернуться, проиграть анимацию,
добавить и отнять предмет, сообщить психике о поступке, пытать удачу и выполнять две задачи
одновременно.

## Фабрика примитивов

Составные задачи не создают примитивы через `new`, а получают фабрику `INpcTaskFactory`. Её
реализация `NpcTaskFactory` создаёт настоящие задачи.

## Задачи-команды

Задачи, которые отдают актору одну команду и ждут её завершения, наследуют `CommandTask`. Она
начинает выполнять команду при старте, сообщает об успехе или провале, когда команда завершилась,
и отменяет её при остановке.

## Для тестов

Точка входа `@peetland/npc-tasks/dev` даёт:

- планирование задач и применение эффектов плана (`plan`, `planNames`, `applyPlanEffects`);
- заглушки задач (`createStubTask`, `createStubPrimitiveTask`);
- фабрику примитивов с настоящими задачами, в которой можно подменить методы
  (`createNpcTaskFactory`, `createNpcTaskFactoryDeps`), и её мок (`createMockedNpcTaskFactory`).
