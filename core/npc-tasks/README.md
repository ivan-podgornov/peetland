# @peetland/npc-tasks

Примитивные задачи, которые нужны любому NPC. Из них составные задачи собирают свои методы.

## Задачи

- **Идти к координатам** (`GoToCoordsTask`) — актор идёт к точке, пока не окажется от неё ближе
  заданного радиуса. В эффектах актор оказывается в точке.
- **Повернуться** (`AchieveAngleTask`) — актор поворачивается на угол с заданной точностью. В
  эффектах актор повёрнут на угол, приведённый к [0, 360).
- **Проиграть анимацию** (`PlayAnimationTask`) — актор проигрывает анимацию. Состояние не меняет.
- **Добавить предмет** (`AddItemTask`) — кладёт предмет в инвентарь. Задача мгновенная.
- **Отнять предмет** (`RemoveItemTask`) — забирает предмет из инвентаря. Выполнить можно, только
  если предмета хватает. Задача мгновенная.
- **Отреагировать на поступок** (`PsycheReactTask`) — сообщает психике о поступке, чтобы поменялись
  чувства. Задача мгновенная. Как поступок меняет чувства, решает психика.
- **Пытать удачу** (`TryLuckTask`) — раз в `TRY_LUCK_PERIOD` бросает шанс, пока не повезёт. Что
  NPC получил, решают следующие задачи плана.
- **Параллельная задача** (`ParallelTask` из `@peetland/htn`) — выполняет основную задачу и
  одновременно с ней фоновую, например, пытает удачу под анимацию поиска в мусорке.

## Фабрика примитивов

Составные задачи не создают примитивы через `new`, а получают фабрику `INpcTaskFactory`. Её
реализация `NpcTaskFactory` создаёт настоящие задачи.

Если цепочку задач нужно повторить несколько раз, например, искать в мусорке пять бутылок подряд,
фабрика собирает повторения через `repeat`. Цепочку создаёт переданная функция, и на каждое
повторение — заново, поэтому у повторений свои экземпляры задач:

```ts
const tasks = npcTaskFactory.repeat(5, () => [
  npcTaskFactory.tryLuck({ chance: 1 / 60 }),
  npcTaskFactory.addItem({
    item: Item.Bottles,
    count: 1,
  }),
]);
```

Число повторений должно быть целым и неотрицательным, иначе `repeat` выбрасывает ошибку. Если
повторений 0, возвращается пустой массив.

## Задачи-команды

Задачи, которые отдают актору одну команду и ждут её завершения, наследуют `CommandTask`: идти к
координатам, повернуться и проиграть анимацию. `CommandTask` начинает выполнять команду при старте,
сообщает об успехе или провале, когда команда завершилась, и отменяет её при остановке.

## Для тестов

Точка входа `@peetland/npc-tasks/dev` даёт фабрику примитивов с настоящими задачами, в которой можно
подменить методы (`createNpcTaskFactory`), и её зависимости (`createNpcTaskFactoryDeps`). Мок
`repeat`, который собирает цепочку один раз, сколько бы повторений ни попросили
(`createMockedRepeat`), позволяет проверить цепочку и число повторений отдельно друг от друга.
Планирование и заглушки задач лежат в `@peetland/htn/dev`.
