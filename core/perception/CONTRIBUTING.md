# @peetland/perception

Восприятие мира. Пока здесь одно чувство — зрение: `VisionSystem` сообщает, каких акторов видит
данный актор. Имя пакета оставляет место будущим чувствам, например слуху.

Пакет зависит от `@peetland/game` и `@peetland/geometry`, обратных зависимостей нет: игры собирают
систему зрения из своих реализаций.

## Система зрения

`VisionSystem` получает реестр акторов, провайдер прямой видимости и геометрию, и отвечает на
вопрос «кого видит этот актор»:

```ts
import { VisionSystem } from '@peetland/perception';

const vision = new VisionSystem({
  registry: actorRegistry,
  los,
  geometry,
});

const visible = vision.getVisibleActors(actor, 50);
```

Актор видит другого, если тот проходит весь каскад проверок:

1. есть в реестре (акторы вне реестра — например, случайные педы — не видны в принципе);
2. находится в радиусе от смотрящего, граница радиуса считается видимой;
3. попадает в сектор зрения смотрящего: вершина — позиция смотрящего, направление — его поворот,
   угловой размер — человеческий угол зрения `HUMAN_FOV_DEG`, 100°. Знание «человеческий угол
   зрения» живёт в этом пакете и не протекает в игры и задачи;
4. прямая видимость до него свободна (см. ниже);
5. не является самим смотрящим и не деспавнен.

Реестр по умолчанию убирает деспавненных акторов сам, но система зрения не полагяется на это и
проверяет сигнал деспавна каждого актора.

## Прямая видимость

Стены и препятствия знает только конкретный мир, поэтому прямую видимость проверяет провайдер
`ILosProvider` с единственным методом `isLineOfSightClear(from, to)`. Реализацию предоставляет
игра:

- `AlwaysClearLos` — провайдер прозрачного мира: прямая всегда свободна. Виртуальный мир
  прозрачен, поэтому виртуальная игра использует его;
- игра с препятствиями оборачивает свой нативный вызов прямой видимости.

## Для тестов

`@peetland/perception/dev` даёт `getPointAt(bearing, distance)`: точку на расстоянии `distance`
от начала координат по направлению `bearing` (0° — север, против часовой стрелки). Удобно
расставлять акторов вокруг смотрящего.
