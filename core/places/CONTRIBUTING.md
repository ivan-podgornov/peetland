# @peetland/places

Места мира: лагерь бездомных, магазины, пункты приёма бутылок, мусорки и места, где можно клянчить.

## Данные и запросы

- **Данные места** (`PlaceData`) хранятся в репозитории: тип места (`PlaceType`), координаты, где
  нужно встать, чтобы им воспользоваться, и угол, на который нужно повернуться.
- **Запросы** (`IPlaces`) — синхронные, потому что места уже загружены: места типа (`ofType`),
  ближайшее место типа (`findNearest`) и есть ли место типа рядом (`isNear`). Запросы создаёт
  фабрика `PlacesFactory` из загруженных мест.

## Для тестов

Точка входа `@peetland/places/dev` даёт данные места (`createPlace`) и мок запросов к местам
(`createMockedPlaces`).
