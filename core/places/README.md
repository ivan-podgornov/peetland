# Места

Дела NPC привязаны к местам мира. NPC подходит к месту и поворачивается как надо — лицом к прилавку
или к мусорке — и только потом берётся за дело.

- **Бомжарня** — лагерь бездомных, где бомж бухает.
- **Магазин** — где покупают пойло.
- **Приёмка** — где сдают пустые бутылки за деньги.
- **Мусорка** — где ищут пустые бутылки.
- **Место для клянчанья** — где просят деньги у прохожих.

Обычно NPC идёт к ближайшему месту нужного типа, а мусорку бомж выбирает случайную, чтобы обходить
разные.

Сейчас все места находятся в Монтгомери: бомжарня, два магазина с выпивкой, приёмка у заднего входа
одного из них, место для клянчанья и десять мусорок возле магазинов, ресторана, торгового центра,
пиццерии и заправки.
