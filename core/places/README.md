# Места

Дела NPC привязаны к местам мира:

- **Бомжарня** — лагерь бездомных, где живут бомжи.
- **Место для распития** — где пьют пойло. У бомжарни Монтгомери такое есть прямо у входа.
- **Магазин** — где покупают пойло и еду.
- **Приёмка** — где сдают пустые бутылки за деньги.
- **Мусорка** — где ищут пустые бутылки.
- **Место для попрошайничества** — где просят деньги у прохожих.
