# Коммиты и ветки

## Коммиты

Сообщения коммитов пишутся по
[гайду Angular](https://github.com/angular/angular/blob/main/contributing-docs/commit-message-guidelines.md):
`<type>(<scope>): <summary>`. Типы берутся из гайда (`feat`, `fix`, `refactor`, `test`, `docs`,
`ci` и другие), а scope — это имя пакета без `@peetland/`, например `events`, `game` или `gta-sa`.
Если изменение затрагивает несколько пакетов, scope — это пакет с главным изменением, а правки в
остальных пакетах — его следствие, например переход на новый API этого пакета. Если главного пакета
нет и пакеты меняются наравне, scope не указывается. Summary пишется на русском. Заголовок пулл
реквеста пишется по тем же правилам.

```
feat(animation-manager): менеджер анимаций в зависимостях
```

## Ветки

Ветка называется `<type>/<описание>`. Тип тот же, что у коммитов, а описание — несколько слов на
английском через дефис:

```
feat/animation-manager
fix/actor-despawn
docs/naming-conventions
```
