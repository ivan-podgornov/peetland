# Документация

Документация лежит в пакете `docs` и собирается в сайт на Docusaurus. Страницы — обычный Markdown
без MDX прямо в пакете, рядом с его конфигом, диаграммы рисуются на Mermaid. Локально сайт
запускается командой `npm start -w @peetland/docs`.

README пакетов не копируются в `docs`: раздел «Пакеты» читает их прямо из пакетов вместе с файлами
из папки `docs` пакета. Относительные ссылки в них должны вести на Markdown внутри пакета, иначе
сборка сайта упадёт на битой ссылке.
