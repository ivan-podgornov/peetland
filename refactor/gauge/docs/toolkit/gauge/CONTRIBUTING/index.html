@peetland/gauge

Шкала (Gauge) — значение от min до max, которое лениво падает по игровому времени, прибавляется (add) и отдаёт уровень (GaugeLevel) по двум порогам. В шкале нет ничего про мир Peetland: на ней построены потребности (@peetland/needs) и зависимости (@peetland/addictions).

import { Gauge, GaugeLevel } from '@peetland/gauge';
import { ManualTime } from '@peetland/timings';

const gauge = new Gauge(
  { value: 80, since: { day: 1, hours: 10, minutes: 0 } },
  {
    min: 0,
    max: 100,
    // Падает на 100 за сутки
    depletion: { amount: 100, minutes: 24 * 60 },
    lowBelow: 25,
    highAbove: 60,
  }
);

const time = new ManualTime({ day: 1, hours: 16, minutes: 0 });

gauge.get(time); // 55: за четверть суток упала на 25
gauge.getLevel(time); // GaugeLevel.Middle
gauge.add(30, time); // 85, и падение отсчитывается от 16:00

Ленивое падение​

Никто не убавляет шкалу по тикам. Она хранит значение и момент игрового времени, когда его выставили (GaugeState), а текущее считает при чтении: значение − depletion.amount × прошло минут / depletion.minutes (TimeSpan из @peetland/timings). Скорость задаётся дробью, а считается сначала умножением, потом делением: так за depletion.minutes значение падает ровно на depletion.amount, без погрешности на границе порога. Если depletion.amount — 0, значение не падает. Значение не опускается ниже min, а если переданное время раньше момента, когда значение выставили, например время перевели назад, не растёт.

Уровни​

Ниже lowBelow уровень Low, выше highAbove — High, а между порогами и на них — Middle. Что значит уровень, решает тот, кто пользуется шкалой: например, у потребностей низкий уровень — срочно, а у зависимостей — тянет.

Прибавление и пределы​

add(amount, time) прибавляет amount к значению на момент time и отсчитывает падение от time. amount может быть отрицательным. Значение всегда держится в пределах от min до max: и в конструкторе, и при прибавлении. Проверять, что значение допустимо, шкала не берётся: это дело того, кто её создаёт.

Только на чтение​

IReadonlyGauge — шкала только на чтение: get, getLevel и getState. getState() возвращает значение и момент, а конструктор собирает из такого же объекта такую же шкалу.

Для тестов​

Точка входа @peetland/gauge/dev даёт опции шкалы (DEFAULT_OPTIONS) — от 0 до 100, падает на 100 за сутки, пороги 25 и 60 — и её состояние (DEFAULT_STATE) — 100 в полночь первого дня.
