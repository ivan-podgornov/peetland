# @peetland/htn

HTN (Hierarchical Task Network) - это подход к планированию поведения NPC, где задача описывается
**иерархией**: сложная задача раскладывается на подзадачи, те - на ещё более простые и так вплоть до
самых примитивных действий. HTN предполагает что пользователь будет сам описывать задачи и способы
их декомпозиции, а планировщик только выбирает наиболее эффективный способ решения задачи при
текущем состоянии мира.

Как пакет устроен и как с ним работать, описано в [CONTRIBUTING.md](./CONTRIBUTING.md).
